# Ectoplasm

A dark Visual Studio Code theme featuring deep blue backgrounds, electric-blue accents, carefully balanced syntax highlighting, and optional neon glow effects.

Part of the **Made by Spook** Ectoplasm theme collection.

## Installation

1. Open the **Extensions** view in Visual Studio Code.
2. Search for **Ectoplasm** by **Made by Spook**.
3. Click **Install**.
4. Select **Ectoplasm** under **Preferences: Color Theme**.

Requires VS Code 1.85 or later.

## Optional Glow

Ectoplasm supports glowing syntax highlighting and cursor effects on macOS desktop VS Code.

- **Enable:** Run `Ectoplasm: Enable Glow` from the Command Palette, then reload VS Code.
- **Disable:** Run `Ectoplasm: Disable Glow`, then reload VS Code.

Glow modifies VS Code's workbench files with explicit confirmation and may trigger an **[Unsupported]** warning. VS Code updates may remove the modification, requiring glow to be enabled again.

Disable glow before uninstalling Ectoplasm. The standard theme works independently of glow.
